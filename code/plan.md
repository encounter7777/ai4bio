# Option 1 项目计划：复现 Struct2SL 并研究蛋白质结构特征的作用

## 1. 项目目标

复现一个有明确记录、使用全部特征的 Struct2SL 模型作为基线，然后通过训练一个移除两侧基因结构特征列的同款模型，估计结构特征表示所带来的贡献。

核心研究问题：

> 在受控的评估方案下，Struct2SL 使用的结构特征能否为合成致死（Synthetic Lethality，SL）基因对预测提供额外的预测信息？

即使实验结果为负面或无法得出明确结论，也属于有效结果。本项目不要求超过论文中报告的性能。

## 2. 项目范围与完成标准

本项目必须完成以下工作：

1. 获取 Struct2SL 作者提供的代码和处理后的数据。
2. 记录代码版本、选用的过滤后 SL 文件、保留的基因和基因对，以及负样本池的构建方法。
3. 删除无序基因对中的重复项，并处理标签相互矛盾的情况。
4. 只采样一次 1:1 的负样本池，并在所有必需的模型比较中重复使用。采样得到的未观测基因对属于**假定负样本**，不能称为经过实验验证的非 SL 基因对。
5. 使用作者提供的蛋白质特征，复现一个完整特征版本的 Struct2SL 基线。无需重新运行 AlphaFold2。
6. 遵循作者发布的 Python 脚本：外层划分 20% 测试集，并在剩余 80% 数据中进行五折训练/验证划分；使用固定随机种子。
7. 每一折的特征缩放器只能在该折训练数据上拟合。模型轮数和参数只能依据验证集选择，不能使用测试集进行选择。
8. 训练第二个模型：移除两个基因对应的结构特征列。两个模型必须使用完全相同的基因对池、标签、外层测试集、折分配、随机种子和调参预算。
9. 报告 AUROC、平均精确率 AP（必须与 `sklearn.metrics.average_precision_score` 的定义一致）以及固定阈值 0.5 下的 F1，同时报告测试集正负样本数量和配对差值。
10. 报告五个已训练模型在同一个测试集上的均值和标准差。必须明确说明：这不是五个相互独立的测试集。
11. 将完整特征模型的复现结果与原论文 Table 3 作背景比较，并解释实验方案或实现上的差异。不要求数值完全一致。

## 3. 数据与基因对构建计划

### 3.1 数据来源检查

在编写数据读取代码前，先检查官方代码仓库和处理后数据的说明。确认实际文件名、列名、标识符、筛选规则、特征定义和负样本候选集合的构建方法。不要猜测这些信息。

记录以下内容：
- 代码仓库地址和准确的 Git commit/revision；
- 处理后数据的来源、下载日期、文件名，以及可行时的文件校验值；
- 选用的过滤后 SL 文件和过滤标准；
- 基因标识符及特征表结构；
- 保留的基因、正样本基因对、负样本候选、采样得到的负样本和最终样本数量。

### 3.2 基因对完整性处理

将基因对视为无序对。例如，(gene A, gene B) 与 (gene B, gene A) 是同一个基因对。

使用稳定的基因标识符，为每个基因对生成确定性的规范表示。删除规范化后重复的基因对，并检测标签相互矛盾的情况。对于冲突，应采用有数据依据且有记录的处理规则。如果无法合理解决，则排除这些基因对，并报告数量和原因。最终数据中不能让同一基因对同时具有正、负两种标签。

### 3.3 负样本池

尽可能遵循作者发布的数据构建流程。建立负样本候选集合后，排除自配对、重复无序基因对以及已知正样本基因对。

使用固定随机种子，只采样一次负样本，数量与保留的正样本数量相同，即 1:1。保存采样后的基因对 ID 和最终数据表。两个模型版本及所有折都必须重复使用这些完全相同的文件，不能为消融实验重新采样。

如果符合条件的候选负样本数量不足，不要擅自改变比例，应停止并记录这一问题。报告中必须说明：未观测基因对只是“假定负样本”，其中可能包含尚未发现的 SL 基因对。

## 4. 实验设计

### 4.1 数据划分

复现作者发布脚本中的外层 20% 测试集划分，以及在剩余 80% 数据中进行的五折训练/验证划分。

检查作者脚本，确认具体使用的划分函数、是否进行分层抽样以及随机种子。保存每个基因对的 ID 和划分结果。完整特征模型与无结构特征模型必须读取同一套固定划分文件。

### 4.2 预处理与数据泄漏防止

对于每一折：
- 只使用该折训练集拟合特征缩放器及其他需要学习参数的预处理步骤；
- 使用训练集拟合得到的变换处理该折验证集和共同的外层测试集；
- 不能使用验证集或测试集拟合预处理步骤；
- 只能依据验证集选择训练轮数和模型参数；
- 不能使用外层测试集进行调参、早停、特征选择或阈值调整。

### 4.3 两个模型版本

**模型 A：完整特征 Struct2SL**

按照作者实现和处理后数据的定义，使用完整的蛋白质序列、蛋白质互作网络（PPI）以及 AlphaFold2 衍生结构特征。

**模型 B：移除结构特征的 Struct2SL**

移除两个基因对应的结构特征列，保留其他所有输入特征及其相对顺序。由于输入维度发生变化，需要单独训练该模型。

模型 A 和模型 B 必须保持以下内容一致：
- 基因对数据池和标签；
- 外层测试集和五折分配；
- 随机种子；
- 预处理规则；
- 仅依据验证集进行模型选择的规则；
- 调参预算和停止策略。

两个模型之间唯一有意改变的实验因素是是否使用结构特征列，以及由此产生的输入维度变化。

### 4.4 评价指标

在共同的外层测试集上，对五个已训练模型分别计算：
- AUROC；
- AP，使用 `sklearn.metrics.average_precision_score`；
- 固定概率阈值 0.5 下的 F1；
- 测试集正样本数和负样本数。

分别计算两个模型版本五次结果的均值和标准差。配对差值统一定义为：

**差值 = 完整特征模型指标 − 无结构特征模型指标**

逐折报告差值，并给出差值的汇总结果。不能将这五次结果描述为来自五个独立测试集。

## 5. 可复现性记录

建立运行清单（manifest），记录：
- 代码仓库 commit 和数据来源；
- 选用的过滤后 SL 文件及过滤流程；
- 基因对规范化方法和冲突标签处理规则；
- 保留的基因/基因对及负样本候选数量；
- 负样本采样比例、随机种子和采样结果文件；
- 外层划分随机种子及五折分配/随机种子；
- 两个模型使用的特征组和具体列；
- 特征缩放方法，以及只在训练集拟合的规则；
- 模型结构、初始化方法、超参数、轮数选择规则和软件版本；
- 指标计算方式和分类阈值；
- 硬件、运行时间，以及相对作者代码的所有改动。

保存配置文件、划分 ID、采样负样本、训练日志、模型检查点和逐样本测试预测结果。

## 7. 时间安排（3–4 周）

### 第 1 周：数据和实验方案
- 克隆官方代码仓库并记录 commit；
- 检查作者脚本和处理后数据；
- 确认数据结构、特征组、筛选规则和负样本构建方式；
- 构建并检查基因对池，一次性采样并固定 1:1 负样本；
- 复现并保存外层测试集和五折划分；
- 交付：数据审计记录、运行清单、固定的基因对和划分文件。

### 第 2 周：完整特征模型复现
- 复现预处理流程和模型结构；
- 确认缩放只在训练集拟合、模型选择只使用验证集；
- 训练五个完整特征模型，并在共同测试集上评价；
- 将结果与论文 Table 3 作背景比较；
- 交付：训练日志、预测结果、指标和实现差异说明。

### 第 3 周：结构特征消融实验
- 创建无结构特征版本，移除两个基因的结构特征列；
- 验证两个版本使用完全相同的样本、标签、划分、随机种子和调参预算；
- 训练五个无结构特征模型；
- 计算评价指标和配对差值；
- 交付：模型对比表和必要的诊断图。

### 第 4 周（如有）：结果解释与收尾
- 检查可复现性文件并调查结果差异；
- 分析结构特征的作用和实验局限；
- 只有在必需实验完成后，才考虑进行一个可选扩展；
- 交付：最终报告、代码、配置、日志和展示材料。

## 8. 风险与应对

| 风险 | 应对方法 |
|---|---|
| 仓库数据结构与预期不一致 | 先检查真实文件和脚本，再编写读取程序；记录实际数据结构 |
| 基因对重复或标签冲突 | 规范化无序基因对，并在训练前进行唯一性和标签一致性检查 |
| 负样本标签存在噪声 | 明确称为假定负样本，并讨论潜在假阴性 |
| 预处理产生数据泄漏 | 缩放器只在训练折拟合，并通过断言或测试验证 |
| 消融实验改变了其他实验条件 | 两个模型共用固定的基因对和划分文件，并比较配置 |
| 测试集被用于调参 | 在测试集评估前固定所有设置，模型选择只依据验证集 |
| 环境不兼容 | 固定依赖版本，并在完整训练前运行小规模流程测试 |
| 无法复现论文分数 | 如实报告结果，并解释数据、划分、代码和环境差异 |

## 9. 可选扩展

只有在全部必需实验完成后，才选择至多一个扩展：
- 基因不相交（gene-disjoint）划分；
- 不平衡测试集，例如正负样本比例为 1:10；
- 额外的已发表模型，例如使用 ESM-2 序列特征的基线。

必须定义评估样本池和保留的基因/基因对。若使用排序指标，还要定义候选池、K 和假定正样本比例。困难候选基因对可以作为未标注的干扰项，但共享通路、属于同一复合物、旁系同源或共同必需性，都不能作为其属于负 SL 标签的证据。
